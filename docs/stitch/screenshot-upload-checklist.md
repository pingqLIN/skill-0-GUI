# Screenshot Upload Checklist

Upload 2 to 4 screenshots with the prompt and summary file.

The goal is to show Stitch the real information density and workflow structure, not to make it copy the current visuals.

## Recommended screenshots

### `01-home-intake.png`

Capture:

- header
- parser mode / bridge status block
- skill URL input
- multiline paste area
- upload zone
- sample scenarios

Purpose:

- establish that this is a workbench with an intake-first homepage
- prevent Stitch from turning the product into a marketing landing page

### `02-workspace-overview.png`

Capture:

- left navigation rail
- main center workspace
- right reviewer / evidence rail
- truth banner
- quick actions

Purpose:

- establish the three-zone desktop layout
- show that this is a dense reviewer console

### `03-checks-evidence.png`

Capture:

- validation panel
- consistency checks
- warnings / errors
- supporting files
- findings / command references if visible

Purpose:

- show the product is evidence-heavy, not a simple document editor

### `04-signoff-export.png`

Capture:

- review status
- reviewer notes
- review summary
- reviewer signoff
- checklist completion
- export actions

Purpose:

- show that sign-off and export are first-class workflow steps

## Capture guidance

- Use desktop viewport screenshots
- Prefer full-window captures over cropped fragments
- Keep text legible
- Avoid uploading more than 4 screenshots
- Do not upload screenshots of source code or tests

## Best pairings

If you only upload 2 screenshots:

1. `01-home-intake.png`
2. `02-workspace-overview.png`

If you upload 4 screenshots:

1. `01-home-intake.png`
2. `02-workspace-overview.png`
3. `03-checks-evidence.png`
4. `04-signoff-export.png`
