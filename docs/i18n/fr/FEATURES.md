# Skill-0 Review Studio Fonctionnalites

## Capacites principales

- Espace d'intake pour un fichier skill principal et des fichiers de contexte optionnels
- Bridge vers le parseur canonique quand un depot local `skill-0` est disponible
- Parseur fallback standalone pour les demos publiques et les revues externes
- Decomposition board pilote par la sortie du parseur
- Dashboard et security matrix pour les findings, la tracabilite et le cadrage du risque
- Semantic review map legere comme surface publique de visualisation
- Edition en memoire et export `.skill.md`

## Limites de la version publique

- La version publique ne fournit pas l'espace 3D interactif
- La version publique ne fournit pas de persistence serveur, de brouillons partages ni d'historique multi-utilisateur
- Une release standalone ne doit pas revendiquer une equivalence stricte avec le parseur canonique
