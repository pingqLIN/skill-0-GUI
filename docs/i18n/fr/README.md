# Skill-0 Review Studio

`Skill-0 Review Studio` est un espace de travail oriente revue pour les sorties du parseur Skill-0.

Position actuelle de la version publique :

- deploiement en mode `standalone`
- l'espace 3D interactif n'est pas inclus dans la version publique
- conservation de la review map legere, des surfaces du parseur et du flux d'export
- cette version doit etre consideree comme une public beta, pas comme un produit final avec persistence

Etat technique actuel :

- verification de types reussie
- tests reussis
- build de production reussi
- verification de sync des shared docs reussie
- serveur standalone et routes API verifies localement en mode proche production
