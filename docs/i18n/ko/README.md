# Skill-0 Review Studio

`Skill-0 Review Studio`는 Skill-0 파서 출력을 검토하기 위한 review-first 작업 공간입니다.

현재 공개판 방향:

- `standalone` 모드로 배포
- 공개판에서는 인터랙티브 3D 작업 공간을 제공하지 않음
- 가벼운 review map, parser 화면, export 흐름은 유지
- 이 버전은 persistence 기반 최종판이 아니라 public beta 로 취급

현재 엔지니어링 상태:

- 타입 체크 통과
- 테스트 통과
- production build 통과
- shared docs sync check 통과
- production 유사 형태의 standalone server 와 API routes 를 로컬에서 검증 완료
