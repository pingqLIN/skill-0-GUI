# Skill-0 Review Studio

`Skill-0 Review Studio` 是以审查为核心的 Skill-0 解析结果工作台。

当前公开版定位：

- 以 `standalone` 模式部署
- 公开版禁用交互式 3D 工作区
- 保留轻量 review map、parser 分析界面与导出流程
- 当前更适合作为 public beta，而不是带持久化的正式终版

当前工程状态：

- 类型检查通过
- 测试通过
- production build 通过
- shared docs sync 检查通过
- 已在本机验证 production 形式的 standalone server 与 API routes
