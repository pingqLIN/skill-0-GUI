# Skill-0 Review Studio

`Skill-0 Review Studio` es un espacio de trabajo centrado en revision para la salida del parser de Skill-0.

Posicion actual de la version publica:

- despliegue en modo `standalone`
- la version publica no incluye el espacio 3D interactivo
- se mantienen el review map ligero, las superficies del parser y el flujo de exportacion
- esta release debe tratarse como public beta, no como producto final con persistencia

Estado tecnico actual:

- type check aprobado
- tests aprobados
- production build aprobado
- shared-doc sync check aprobado
- servidor standalone y rutas API verificados localmente en modo similar a produccion
