# Skill-0 Review Studio Funciones

## Capacidades principales

- Espacio de intake para un archivo skill principal y archivos de contexto opcionales
- Bridge al parser canonico cuando existe un repositorio local `skill-0`
- Parser fallback standalone para demos publicas y revision externa
- Decomposition board basado directamente en la salida del parser
- Dashboard y security matrix para findings, trazabilidad y evaluacion de riesgo
- Semantic review map ligero como superficie publica principal
- Edicion en memoria y exportacion `.skill.md`

## Limites de la version publica

- La version publica no incluye el espacio 3D interactivo
- La version publica no ofrece persistencia del lado servidor, borradores compartidos ni historial multiusuario
- Un despliegue solo standalone no debe afirmar equivalencia estricta con el parser canonico
