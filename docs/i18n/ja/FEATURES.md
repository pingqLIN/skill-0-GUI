# Skill-0 Review Studio 機能説明

## コア機能

- 主 skill ファイルと追加 context files を取り込む intake ワークスペース
- ローカルの `skill-0` が利用可能な場合の canonical parser bridge
- 公開デモや外部レビュー向けの standalone fallback parser
- parser 出力を基準にした decomposition board
- findings、traceability、risk framing をまとめる dashboard と security matrix
- 公開版の主要可視化としての軽量 semantic review map
- メモリ上での編集と `.skill.md` のエクスポート

## 公開版の制限

- 公開版では対話型 3D ワークスペースを提供しない
- 公開版では server-side persistence、共有ドラフト、複数ユーザー履歴を提供しない
- standalone のみの公開では canonical parser と完全同一とは主張しない
