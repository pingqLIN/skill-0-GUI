# Skill-0 Review Studio

`Skill-0 Review Studio` は、Skill-0 パーサー出力をレビューするためのワークスペースです。

現在の公開版方針:

- `standalone` モードで公開
- 公開版では対話型 3D ワークスペースを無効化
- 軽量な review map、parser 画面、エクスポート機能を維持
- 永続化付きの最終製品ではなく public beta として扱う

現在の技術状態:

- 型チェック通過
- テスト通過
- production build 通過
- shared docs sync チェック通過
- production 相当の standalone server と API routes をローカルで検証済み
