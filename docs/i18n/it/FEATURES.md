# Skill-0 Review Studio Funzionalita

## Capacita principali

- Spazio di intake per un file skill principale e file di contesto opzionali
- Bridge verso il parser canonico quando e disponibile un repository locale `skill-0`
- Parser fallback standalone per demo pubbliche e review esterne
- Decomposition board guidato direttamente dall'output del parser
- Dashboard e security matrix per findings, tracciabilita e valutazione del rischio
- Semantic review map leggera come superficie pubblica principale
- Modifiche in memoria ed export `.skill.md`

## Limiti della release pubblica

- La release pubblica non include lo spazio 3D interattivo
- La release pubblica non offre persistenza lato server, bozze condivise o cronologia multiutente
- Un deploy solo standalone non deve dichiarare equivalenza stretta con il parser canonico
