# Skill-0 Review Studio

`Skill-0 Review Studio` e uno spazio di lavoro orientato alla revisione per l'output del parser Skill-0.

Posizionamento attuale della release pubblica:

- deploy in modalita `standalone`
- la release pubblica non include lo spazio 3D interattivo
- vengono mantenuti review map leggera, superfici del parser e flusso di export
- questa versione va considerata una public beta, non un prodotto finale con persistenza
