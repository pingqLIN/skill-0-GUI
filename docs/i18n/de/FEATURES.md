# Skill-0 Review Studio Funktionsuebersicht

## Kernfunktionen

- Intake-Arbeitsbereich fuer eine Haupt-Skill-Datei plus optionale Kontextdateien
- Canonical Parser Bridge, wenn ein lokales `skill-0` Repository verfuegbar ist
- Standalone-Fallback-Parser fuer oeffentliche Demos und externe Reviews
- Decomposition Board direkt aus der Parser-Ausgabe
- Dashboard und Security Matrix fuer Findings, Rueckverfolgbarkeit und Risikobewertung
- Leichte semantic review map als oeffentliche Visualisierung
- Bearbeitung im Speicher und Export als `.skill.md`

## Grenzen der oeffentlichen Version

- Die oeffentliche Version enthaelt keinen interaktiven 3D-Arbeitsbereich
- Es gibt keine serverseitige Persistenz, keine geteilten Entwuerfe und keine Mehrbenutzer-Historie
- Bei reinem Standalone-Deployment sollte keine vollstaendige Gleichheit mit dem canonical parser behauptet werden
