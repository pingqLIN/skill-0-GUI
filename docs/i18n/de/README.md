# Skill-0 Review Studio

`Skill-0 Review Studio` ist eine review-orientierte Arbeitsoberflaeche fuer Skill-0-Parser-Ausgaben.

Aktuelle Veroeffentlichungsstrategie:

- Deployment im `standalone`-Modus
- Kein interaktiver 3D-Arbeitsbereich in der oeffentlichen Version
- Der leichte Review-Map, die Parser-Oberflaechen und der Export bleiben erhalten
- Diese Version ist als public beta gedacht, nicht als finales Produkt mit Persistenz

Aktueller Engineering-Status:

- Type Check erfolgreich
- Tests erfolgreich
- Production Build erfolgreich
- Shared-Docs-Sync-Check erfolgreich
- Standalone-Server und API-Routen im produktionsnahen Modus lokal verifiziert
